# Code Audit — 2026-11-08

Scope: every tracked source file (172 files, ~33.5k lines). The audit checked three things:
display errors and duplicate elements, broken links/buttons, and whether the
registration flow is accurate and works well for teenagers.

Verification: `tsc --noEmit` passes, `vite build` passes. A Playwright run covered
sign-in → register → onboarding (all skip paths plus Retake) → dashboard (desktop and
390px mobile) with **0 console/page errors**.

## 3. Registration flow (accuracy and teen-friendliness)

| # | Issue | Fix |
|---|-------|-----|
| 1 | After sign-up the "check your email" toast vanished after a few seconds, and it appeared even when no confirmation was needed | Notice stays on screen (and switches to Sign In). If Supabase returns a session straight away, the student goes straight in |
| 2 | Raw Supabase errors (`Invalid login credentials`, `User already registered`) | Short, friendly messages (typo hint, "check spam", "try signing in", network) |
| 3 | The name typed at sign-up was asked for again, and "Skip" used the email prefix (shown as "Hai, teen") | Name is pre-filled, and Skip uses the sign-up name |
| 4 | "Retake Survey" sent the student back to Welcome, so they had to fill in their personal details again | Goes straight back to the survey |
| 5 | No way to go back between survey sections | Added a "← Back" button |
| 6 | The persist effect could upsert twice and call `onOnboardingComplete` more than once | Guarded with a ref, so it runs once |
| 7 | The "max 10 skills" toast was fired inside a state updater, which could show it twice | Moved outside the updater |
| 8 | **Every student could see and switch on Admin Mode** (revenue, profit sharing, affiliates) | Shown only when `app_metadata.role` is `admin` or `super-admin` (set server-side, so students can't edit it) |
| 9 | Accessibility: auth labels weren't linked to their inputs, and there was no `autocomplete` | Added `htmlFor`/`id`, `autocomplete`, `aria-pressed` on survey answers, and `type="button"` |
| 10 | Teen safety | Password hint ("don't share it"), "Under 13? Ask a parent or guardian", and the Universal sidebar/mobile nav are now consistently in English |

## Still open (not changed in this audit)
- JS bundle is 1.4 MB in one chunk. Code-splitting with `React.lazy` per dashboard page is recommended.
- ~25 features still show "coming soon". They are now honest about it instead of doing nothing.
- QuickActions/HeroSection are in BM only, including for Universal-mode students. This is a product decision.
- Admin protection is still only on the client. Supabase RLS policies must enforce it on the server.
